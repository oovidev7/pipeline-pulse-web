Base card for all v2 profile surfaces (quick stats, snapshots, leaderboards). Flat white, 8px radius, zinc border that lifts on hover — no shadows.

```jsx
<StatCard style={{ padding: '12px 16px' }}>…</StatCard>
<StatCard emphasis style={{ padding: 24 }}>…anchor card…</StatCard>
```

Set padding inline (`px-4 py-3` ≈ `'12px 16px'` for stat tiles, 16 for columns, 24 for the verdict card).
